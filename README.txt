# Hospital Management System (HTML, CSS, JavaScript)

This version uses only frontend technologies:
- `index.html` — page structure and forms
- `style.css` — responsive dashboard design
- `script.js` — application behavior and browser localStorage

## How to run
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Use the menu to manage patients, doctors, and appointments.

The data is stored in the current browser using localStorage. It stays in that browser on that device, but it is not shared with other devices and is not a secure database.

## Included features
- Dashboard statistics
- Add and search patients
- Add and remove doctors
- Book appointments
- Mark appointments completed or cancelled
- Delete records
- Responsive layout for mobile and desktop

## Before submitting
Test all features and add your name, roll number, college, and internship details if required. Check the internship portal for its exact submission requirements.

Educational demo only: do not use real patient medical or personal data. This frontend-only version has no authentication or server-side database.
